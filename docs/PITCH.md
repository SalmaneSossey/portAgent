# 🎤 Pitch - PortAgent Trade Copilot

## Le Problème 😫

> **45 minutes** pour remplir un seul formulaire d'importation sur PortNet

Les importateurs marocains perdent un temps précieux à :
- Saisir manuellement des données répétitives
- Chercher les bons codes douaniers (HS)
- Comprendre des réglementations complexes
- Corriger des erreurs de classification

**Résultat :** Frustration, retards, erreurs coûteuses

---

## Notre Solution 💡

### PortAgent : Le Copilote IA pour PortNet

Un assistant conversationnel **intégré directement** dans l'interface PortNet qui :

1. **Comprend** vos besoins en langage naturel
2. **Extrait** automatiquement les données des factures
3. **Valide** le dossier avant soumission
4. **Soumet** en un clic à PortNet

---

## La Démo 🎬

```
👤 Utilisateur: "Je veux importer du textile de Chine"

🤖 PortAgent: "Parfait ! Voici les options :"
   [📋 EI - Engagement d'Importation]
   [📄 LI - Licence d'Importation]

👤 Clic sur EI

🤖 "De quel pays provient votre marchandise ?"
   [🇨🇳 Chine] [🇫🇷 France] [🇪🇸 Espagne]

👤 Clic sur Chine

🤖 "Quelle est la marchandise ?"
   [👕 Textile] [📱 Électronique] [⚙️ Machines]

👤 Clic sur Textile

🤖 "Téléversez votre facture"
   📎 Upload facture.pdf

🤖 "Données extraites automatiquement :
    • Fournisseur: Guangzhou Textiles Co.
    • Montant: 45,000 USD
    • Date: 01/02/2026
    
   [✓ Confirmer] [✏️ Modifier]"

👤 Clic sur Confirmer

🤖 "✅ Validation réussie !
    📤 Soumettre à PortNet ?"

👤 Clic sur Soumettre

🤖 "🎉 Dossier soumis !
    Référence PortNet: PN-2026-00142"
```

**Temps total : 2 minutes** (vs 45 minutes avant)
